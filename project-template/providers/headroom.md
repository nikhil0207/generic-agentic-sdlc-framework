# Headroom Provider Descriptor

Headroom is an external optional context-optimization provider. It is disabled by default and has evidence authority `NONE`. Only Agents 05, 15, 20, 40, 50, 60, and 100 may consume output in ENABLED after human approval and fidelity evidence. SHADOW output is quarantined and comparison-only. Protected evidence remains retrievable with immutable references and hashes; failures fall back to original context.
