# Graphify Provider Descriptor

Graphify is an external optional code-intelligence provider. It is disabled by default and produces `CODE_INTELLIGENCE_EVIDENCE` with `SUPPLEMENTAL_ONLY` authority. Only Agents 15, 20, 40, and 50 may consume corroborated output. Repository evidence wins disagreements. Missing, stale, partial, unsupported, malformed, or unverified output falls back to direct repository inspection.
